# Java Intro
#2 Java Intro
Java Intro nos indica como guardar informacion dentro de una variable en este caso una variables esta guardando el nombre "Jhon" tambien un saludo.

public class Main {
  public static void main(String[] args) {
    String name = "John";
    System.out.println("Hello " + name);
  }
}
